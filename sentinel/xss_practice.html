Can a comment become a computer instruction?

XSS means a website mistakenly runs code supplied as content. Imagine a comment box that should display words, but instead lets those words change the page.

How to fix it

Show comments as text, not executable HTML. Use context-appropriate output encoding, safe DOM APIs and a restrictive Content Security Policy as an additional defense.
